How it works

What does this comparer check?

  1. The application looks inside each file's records array.
  2. It extracts the user only.
  3. The two collections of users are compared.
  4. Users appearing in both files are displayed as "mutual victors".
Important: Since we only need mutual victors, this application completely ignores the link, percent, and hz properties.
